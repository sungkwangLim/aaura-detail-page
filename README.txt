상세페이지0827 PSD 기반 HTML/CSS 레이아웃

1. index.html: Figma 네 프레임을 그대로 사용한 고품질 기본 버전입니다.
2. semantic.html: 텍스트와 카드 구조를 HTML/CSS로 분리한 편집용 버전입니다.

4. styles.css: 편집용 버전의 레이아웃 스타일입니다.
5. assets 폴더에는 Figma에서 내려받은 원본 이미지가 들어 있습니다.

PSD 원본 크기: 1200 x 23285 px
